# Corewise.Academy

Home of the CoreWise Academy website.

The willaicite / geo-audit project that previously lived in this repo moved with full history to [github.com/ryanportfolio/willaicite](https://github.com/ryanportfolio/willaicite). The live product is at [willaicite.com](https://willaicite.com).

## What lives here

- `design/` holds the CoreWise Academy mockups and the Alembic titling typeface.
- `.claude/reference/design-learnings.html` is the design-study dossier that informs the academy site's visual direction.
