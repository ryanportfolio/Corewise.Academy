## Prerequisites and misconceptions

- Reader has one recurring task and knows what a skill and scheduled task are. Link the existing introductions.
- A working chat does not prove the scheduled environment has the same tools or context.
- Editing a local skill does not automatically update a remote routine. Clarify the video's broad update claim using Anthropic's skill-location documentation.
- Cloud execution removes dependence on the laptop, but does not guarantee that every run succeeds.
- Green status and an assistant's success sentence are insufficient evidence of complete work.
- A frequent schedule can create more review work than value.

## Exercise and quote

Exercise: test one small workflow, save it as a skill, rerun in a fresh session, deliberately test a missing source, and run the actual scheduled configuration before enabling it. This is our exercise, distilled from the lesson rather than copied from an on-screen prompt.
