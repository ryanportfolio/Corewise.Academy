## Verification and source corrections

Official pages read October 30, 2026:

- [Model, effort, and thinking settings](https://support.claude.com/en/articles/8664678-change-the-model-effort-and-thinking-settings): model and effort are separate choices.
- [Choosing the right effort level](https://academy.claude.com/tutorials/choosing-the-right-effort-level-in-claude-code): begin at a model's default and change based on results; Ultracode combines xhigh effort with workflow orchestration.
- [Advisor](https://code.claude.com/docs/en/advisor): main model can consult a second model at decision points. Support depends on the model pairing and account access; no claim of free use.
- [Usage and length limits](https://support.claude.com/en/articles/11647753-how-do-usage-and-length-limits-work) and [usage credits](https://support.claude.com/en/articles/12429409-manage-usage-credits-for-paid-claude-plans): shared product usage, model-dependent context, verified Ultra exception, separate API credits.
- [Cowork and chat merger](https://claude.com/blog/cowork-is-now-claude): announced September 16, 2026. Treat separate app categories in the video as a description that can differ from the reader's UI.
- [Desktop](https://code.claude.com/docs/en/desktop): local sessions, side chats, Windows shortcut, session coordination, Remote Control distinction.
- [Duet](https://support.claude.com/en/articles/17631495-get-started-with-claude-duet): final opened page lists Pro, Max, Ultra; US waitlist; background work counts toward usage. Earlier search snippet omitted Ultra, so use the current page.
- [Dashboards and Motion](https://claude.com/resources/articles/dashboards-and-motion): Docs/Slides/Design on all plans, Dashboards paid beta, Motion Team/Enterprise beta; code animation; standalone Design closes December 14, 2026.
- [Move from standalone Claude Design to Claude](https://support.claude.com/en/articles/17440474-move-from-standalone-claude-design-to-claude): direct migration instructions. Projects move gradually; chats and comments do not move with them. Guide links readers here without instructing a migration itself.
- [Memory](https://code.claude.com/docs/en/memory), [skills](https://code.claude.com/docs/en/skills), [extension overview](https://code.claude.com/docs/en/features-overview), [mods](https://code.claude.com/docs/en/plugins/mods/overview): distinguish saved context, procedure, tools, distribution, and executable customization. Mods run with user permissions.
- [Permissions](https://code.claude.com/docs/en/permissions): six current modes, including dontAsk; written rules do not enforce access.
- [Subagents](https://code.claude.com/docs/en/sub-agents), [Projects](https://code.claude.com/docs/en/claude-projects), [goals](https://code.claude.com/docs/en/goal): separate context, coordinating threads, transcript-based evaluator and failure conditions.
- [Desktop schedules](https://code.claude.com/docs/en/desktop-scheduled-tasks) and [cloud schedules](https://code.claude.com/docs/en/routines): current shared name is scheduled tasks, formerly routines; local requires awake computer and open app.
