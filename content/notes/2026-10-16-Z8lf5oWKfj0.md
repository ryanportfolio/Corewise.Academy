## Prerequisites, misconceptions and exercise

- Reader: someone directing a coding agent for a small business application; comfortable giving tasks, need not already know DDD.
- Prerequisite: Brief the model like a brilliant new hire.
- Misconceptions to correct: a detailed spec proves the implementation stays maintainable; one term means the same thing in every department; a runnable page proves the business rule; more effort fixes missing evidence; a prototype alone proves readiness for real users.
- Original exercise: define an order and the event that accepts it, build a local prototype using sample records, inspect a failing case and the expected successful case, then change a rule and rerun checks. No purchases, external connections or production deployment required.
- Exact short quote candidate: "a good code base is a code base that's easy to make changes in." (28:54-28:56, 14 words). Keep total direct video quotation below 25 words.
