## Placement

Create **No. 57, Give your coding agent a finish line**, in Agents & Automation at practitioner level. The new job is writing one request whose deliverable, check, routine decision paths, and stopping point are explicit. Guide No. 16 covers infrastructure for long runs; No. 29 covers rerun loops; No. 30 covers instruction pruning; No. 38 covers gradually granting permission. This guide links to them where they genuinely intersect.

## Prerequisites and misconceptions

- Reader should know that a coding agent can inspect files, edit, run commands, and open a PR. Link to No. 38 for the permission progression.
- “Keep working until green” is incomplete when the relevant failure is absent from CI. Ask for a behavior check tied to the original symptom.
- A prompt can set a completion condition. It cannot create missing tools, traffic, tests, or permission. A missing check must be reported as a gap.
- Delegating routine choices in a request does not imply authority to merge, deploy, change production settings, or expand the task. Name those boundaries.

## Possible exercise

Take a stalled coding-agent request. Rewrite it with a concrete result, observed pass/fail check, allowed choices if an obstacle appears, and an exact stop condition. Run it in a low-stakes branch. Compare final claims with test output or a reproduced behavior, and stop at a draft PR.
